**VIVA Questions:**

1.What is the Knapsack Problem?

Ans:It is an optimization problem where we select items to get maximum value without exceeding the given capacity.

2.What are the two main types of Knapsack?

Ans: 0/1 Knapsack and Fractional Knapsack.

3.What is 0/1 Knapsack?

Ans:Each item can be either selected completely (1) or not selected (0). We cannot take a fraction of an item.

4.Which algorithm is commonly used for 0/1 Knapsack?

Ans: Dynamic Programming (DP) is commonly used.

5.What is the time complexity of 0/1 Knapsack using DP?

Ans :O(n × W), where n is the number of items and W is the knapsack capacity.

One-line trick to remember:

 Knapsack = Maximum Value + Limited Capacity + Select Items.
